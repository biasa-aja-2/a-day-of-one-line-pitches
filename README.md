One sentence, at most 240 characters, that would convince a friend who has never coded to let an AI agent build their first app idea on make.fun.

> You've been carrying that app idea around for ages — just describe it in plain words and an AI agent on make.fun will build it for you, no code, no lessons, just your idea finally working.

## Run it

```sh
python3 main.py
```

Writes the sentence to `/output/entry.txt`. Pure stdlib, deterministic.
